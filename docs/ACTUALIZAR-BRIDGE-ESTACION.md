# Probar / actualizar la estación en ESTA PC

Leé la guía completa: [`scripts/LEEME.md`](../scripts/LEEME.md).

## Lo más simple

1. Explorador → `Desktop\LG\scripts\`
2. Click derecho en **`02-reiniciar-estacion.cmd`** → **Ejecutar como administrador**
3. En el navegador: https://mss-guard.web.app → Admin → Puertas → Probar apertura

## Primera instalación

1. Admin → Lectores → Generar código
2. **`01-instalar-estacion.cmd`** como Administrador
3. Pegá el código

## Apertura a distancia (opcional)

Solo si la puerta abre por internet: **`03-arrancar-apertura-por-internet.cmd`**
